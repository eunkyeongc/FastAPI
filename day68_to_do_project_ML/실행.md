python ml/train_model.py
# → ml/artifacts/latest.pkl 생성됨


## 2. 평소처럼 서버 실행

uvicorn main:app --reload
# 터미널에'[INFO]카레고리 예측 모델 로드 완료' 출력 확인

 
# 새로운(다른) 터미널에서 실행하기

streamlit run streamlit_app.py

## 4. 예측 연결  
`ervices/category_service.py` 작성 → `todo_service.py`의 `create_todo`에서 호출하도록 연결 → Swagger에서 Todo 생성 후 응답에 `predicted_category`가 채워진 걸 확인

## 5. 확정 엔드포인트

`PATCH /todos/{id}/category` 추가 → Swagger에서 직접 호출해 `final_category`가 저장되는 걸 확인

## 6. 모니터링

`routers/ml.py`의 `/admin/model-accuracy` 호출 → 지금까지 확정한 Todo들의 정확도 확인

## 7. 재학습

일부러 예측을 틀리게 유도할 수 있는 애매한 제목으로 여러 개 만들고 확정값을 다르게 지정 → `retrain.py` 실행 → 정확도 변화 관찰
